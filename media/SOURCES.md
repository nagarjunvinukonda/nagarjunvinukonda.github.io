# Portfolio animation sources

The portfolio uses short, silent MP4 loops for GIF-like playback. Company and framework reference footage is credited next to each player; these clips do not represent personal authorship of the depicted demonstrations.

| File | Source | Use |
| --- | --- | --- |
| tri.mp4 | https://toyotaresearchinstitute.github.io/lbm1/videos/bike.mp4 | 10–16 seconds; TRI company research context |
| neuro42.mp4 | https://www.neuro42.ai/product-page | 18–25 seconds of the official neuro42 product animation; MRI workflow and equipment positioning |
| forterra.mp4 | https://www.forterra.com/ | 2–8 seconds of the official Tested_1 vehicle footage |
| smolvla.mp4, pick-place.mp4 | https://huggingface.co/blog/smolvla | Cropped views of the public task-variation demo; reference footage, not personal policy rollouts |
| mimic.mp4 | https://mimicgen.github.io/resources/new_robots/panda.mp4 | Public Franka manipulation simulation; reference footage |
| bci.mp4 | ../images/BCI.gif | Original portfolio BCI project, compressed |
| turtlebot.mp4 | ../images/PID_control.gif | Original portfolio PID project, also used with an explicit platform-demo caption on the DQN card |
| driving.mp4 | ../images/Behaviour_planning.gif | Original portfolio behavior-planning animation, credited as related project footage on the behavior-cloning card |

JPG files are the corresponding first-frame fallbacks. Play/pause controls and reduced-motion support are provided in scripts/portfolio-media.js.
